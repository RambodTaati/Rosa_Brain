# Java basics for web learners (original)

Java is a statically typed, compiled-to-bytecode language running on the JVM. Common in enterprise web backends.
Entry: public class Main { public static void main(String[] args) { System.out.println("hi"); } }
Types: int, long, double, boolean, char; reference types like String, objects, arrays.
var for local inference when the type is obvious (Java 10+).
Classes and objects: fields, constructors, methods. Access modifiers public/protected/private.
Inheritance: extends one class; implements multiple interfaces. Prefer composition when possible.
Records (modern Java): record User(String id, String email) {} for immutable data carriers.
Collections: List, Map, Set from java.util. List.of, Map.of for small immutables.
Generics: List<String> names = new ArrayList<>();
Exceptions: checked vs unchecked; catch specifically; try-with-resources for AutoCloseable.
Streams: list.stream().filter(...).map(...).collect(Collectors.toList());
Packages organize code; Maven/Gradle manage dependencies.
HTTP servers often use Spring Boot or Jakarta EE — conceptual mapping: controllers validate input, services hold logic, repositories talk to DB.
JDBC with PreparedStatement for SQL — same injection defense as other languages.
Nullability: Optional<T> for explicit absence; avoid returning null from new APIs when Optional fits.
Equals/hashCode contracts matter for maps/sets; records implement them correctly for components.
Practice: write a record and a method that filters a List<User> by domain.
Practice: try-with-resources sketch opening a resource and reading lines.
Q: Why PreparedStatement? A: Binds parameters safely and helps prevent SQL injection.
Q: What is a Java record? A: A concise immutable data carrier with constructor, accessors, equals, hashCode, toString.
