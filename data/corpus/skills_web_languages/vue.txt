# Vue essentials (original)

Vue is a progressive framework for building UIs with a template + script model (Options or Composition API).
Single File Component sketch:
<script setup>
import { ref, computed } from "vue";
const count = ref(0);
const doubled = computed(() => count.value * 2);
function inc() { count.value++; }
</script>
<template>
  <button @click="inc">{{ count }} ×2 = {{ doubled }}</button>
</template>
refs unwrap in templates but need .value in script.
v-bind (:prop) and v-on (@event) directives. v-if / v-show for conditional display. v-for with :key.
v-model binds form inputs two-way (syntax sugar over prop + emit).
Props down, events up: defineProps / defineEmits in script setup.
Watchers: watch(source, callback) for side effects when data changes.
Lifecycle: onMounted, onUnmounted for DOM-related setup/cleanup.
Vue Router maps paths to components. Pinia commonly stores shared state.
Reactivity system tracks dependencies — mutate reactive objects carefully; replace arrays immutably when needed for clarity.
Defensive: same XSS rules — do not v-html untrusted content.
Practice: counter with computed doubled value.
Practice: list with add/remove and keyed v-for.
Q: ref vs reactive? A: ref wraps a single value (.value); reactive makes an object deeply reactive — teams often prefer ref for consistency.
Q: Why :key on v-for? A: Stable identity for efficient and correct DOM reuse.
