# PHP web basics (original)

PHP is a server-side language commonly paired with HTML templates and SQL databases.
Files typically start with <?php. Echo or return strings for responses. Modern PHP uses strict_types.
declare(strict_types=1);
function add(int $a, int $b): int { return $a + $b; }
Variables: $name = "Ada"; arrays $xs = [1, 2, 3]; associative arrays as maps.
Superglobals: $_GET, $_POST, $_SERVER, $_SESSION, $_COOKIE — treat as untrusted input.
Filter and validate: filter_input, or explicit checks. Prefer frameworks' request objects when available.
Sessions: session_start(); store server-side session data; regenerate id on login.
Password hashing: password_hash / password_verify (never invent crypto).
PDO for databases with prepared statements:
$sth = $pdo->prepare("SELECT id FROM users WHERE email = ?");
$sth->execute([$email]);
Templating: escape output with htmlspecialchars($s, ENT_QUOTES, "UTF-8") when printing into HTML.
Composer autoloading and PSR-4 namespaces structure larger apps.
Error reporting: display_errors off in production; log instead.
Front controller pattern: route all requests through index.php with a router.
JSON APIs: header("Content-Type: application/json"); echo json_encode($data, JSON_UNESCAPED_UNICODE);
Defensive: CSRF tokens on state-changing forms; SameSite cookies; prepared SQL; output escaping; upload checks.
Practice: sketch a PDO SELECT by id with a prepared statement and a 404 when missing.
Practice: show a form value escaped in HTML.
Q: Why htmlspecialchars on output? A: Prevents HTML injection/XSS when rendering untrusted text.
Q: How to store passwords? A: password_hash with a modern algorithm; verify with password_verify.
