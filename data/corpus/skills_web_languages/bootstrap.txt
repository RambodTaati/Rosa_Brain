# Bootstrap overview (original)

Bootstrap is a CSS (and optional JS) toolkit providing a responsive grid, components, and utility classes.
Include Bootstrap CSS via build tooling or a vendor file you manage — prefer local/vendor copies in offline curricula.
Grid: .container > .row > .col-md-6 etc. Columns sum to 12 per row in classic Bootstrap grid.
Utilities: .d-flex, .justify-content-between, .m-3, .p-2, .text-center, .fw-bold — compose spacing and alignment quickly.
Components: buttons (.btn .btn-primary), cards, navbar, modal, alerts. Use documented markup structures for accessibility (roles, labels).
Responsive breakpoints via prefixes: col-12 col-md-6 stacks on small screens and splits on medium+.
Customize with CSS variables in modern Bootstrap versions rather than editing compiled CSS by hand.
JS components need their scripts and often button data attributes — ensure keyboard access still works.
Do not fight the grid with heavy custom floats; extend with your own classes for brand look.
Practice: build a responsive two-column card layout with utility classes.
Practice: a navbar that collapses on small screens using Bootstrap's navbar patterns.
Q: What is the Bootstrap grid based on? A: A 12-column responsive layout with containers, rows, and columns.
Q: Why utilities? A: Fast, consistent spacing/alignment without writing unique one-off CSS for every margin.
