# Practice Q&A across web languages (original)

Q: What belongs in the HTML head? A: Meta charset, viewport, title, links to CSS, and deferred scripts as needed.
Q: Name three semantic HTML landmarks. A: header, main, footer (also nav, aside, article, section).
Q: How do you associate a label with an input? A: Match label for to the input id (or wrap the input in the label).
Q: Which form enctype is required for file uploads? A: multipart/form-data.
Q: What does box-sizing: border-box change? A: Width/height include padding and border.
Q: Flexbox is best for which layouts? A: One-dimensional alignment of items in a row or column.
Q: Give a fluid grid track recipe. A: repeat(auto-fit, minmax(16rem, 1fr))
Q: Why include viewport meta? A: So mobile browsers size the layout viewport to the device width.
Q: const vs let in JavaScript? A: const blocks rebinding; let allows reassignment; both are block-scoped.
Q: Why prefer ===? A: It compares without type coercion.
Q: Safe way to put plain text in the DOM? A: textContent (or createTextNode), not innerHTML with untrusted strings.
Q: Does fetch reject on HTTP 404? A: No; check res.ok or status.
Q: What does await do inside async functions? A: Pauses that function until the promise settles.
Q: TypeScript types at runtime? A: Erased; they exist for compile-time checking only.
Q: unknown vs any in TypeScript? A: unknown requires narrowing; any disables checking.
Q: Python open encoding for text? A: Prefer encoding="utf-8" explicitly.
Q: How to avoid SQL injection? A: Bound parameters / prepared statements only.
Q: INNER JOIN vs LEFT JOIN? A: INNER matching rows only; LEFT keeps all left rows.
Q: PHP password storage? A: password_hash and password_verify.
Q: Why htmlspecialchars in PHP templates? A: Escape HTML special characters to reduce XSS risk.
Q: Java try-with-resources purpose? A: Auto-close AutoCloseable resources to avoid leaks.
Q: What is a Java record? A: Immutable data carrier with generated accessors and equality.
Q: C string termination? A: Null-terminated char arrays; track sizes carefully.
Q: C++ RAII idea? A: Resource lifetime tied to object lifetime via constructors/destructors.
Q: C# type for currency? A: decimal.
Q: React state updater form when depending on previous state? A: setCount(c => c + 1)
Q: Why keys in React lists? A: Stable identity across renders for correct reconciliation.
Q: Node lockfile purpose? A: Reproducible dependency trees.
Q: Vue v-for needs what for stable identity? A: A unique :key.
Q: Is jQuery required on modern sites? A: No; native DOM and fetch usually suffice.
Q: Bootstrap grid column count? A: 12 columns per row in the classic grid.
Q: JSON trailing commas? A: Invalid in standard JSON.
Q: XXE defense? A: Disable external entity resolution when parsing untrusted XML.
Q: CSS logical property example? A: margin-inline-start instead of margin-left for RTL-friendly layout.
Q: Event delegation means? A: Handling child events on a common parent via event.target.
Q: AbortController use case? A: Cancel fetch when a newer request supersedes it.
Q: ARIA for current nav link? A: aria-current="page".
Q: Preferred button type in forms? A: Explicit type="submit" or type="button" to avoid ambiguity.
Q: What is CORS? A: Browser-enforced cross-origin request policy based on server headers.
Q: Where should session secrets live in browsers? A: Prefer HttpOnly Secure cookies, not localStorage.
Q: SQL LIMIT purpose? A: Cap rows returned to protect performance and UX.
Q: Python mutable default antipattern? A: def f(x=[]): — use None and create a new list inside.
Q: CSS specificity winner roughly? A: Inline > id > class > element (then order).
Q: Sticky positioning? A: Toggles between relative and fixed-like based on scroll thresholds.
Q: Module script attribute? A: type="module" on script tags for ESM in browsers.
Q: Promise.all behavior on reject? A: Rejects fast when any input promise rejects.
Q: Vue ref in script vs template? A: Use .value in script; auto-unwrap in template.
Q: ASP.NET Core DI idea? A: Register services and inject dependencies rather than newing everywhere.
Q: Image alt for decorative image? A: Empty alt="" so assistive tech can skip it.
Q: Parameter markers in PDO? A: Use ? or named placeholders with prepare/execute.
Q: Grid vs table for page layout? A: CSS grid/flex for layout; HTML tables for tabular data.
Q: What does res.json() return? A: A promise that resolves to parsed JSON.
Q: TypeScript interface vs type alias? A: Both describe shapes; interfaces merge by name; prefer consistency per codebase.
Q: Secure file upload checks? A: Validate size/type server-side, store safely, do not trust client MIME alone.
Q: prefers-reduced-motion? A: Media query to reduce/disable non-essential animation.
Q: What is JSX? A: Syntax sugar for React element trees compiling to function calls.
Q: Node path traversal defense? A: Resolve paths and ensure they stay under an allowed root directory.
Q: Bootstrap utility example? A: d-flex, m-3, p-2, text-center for quick layout/spacing.
Q: XML well-formed means? A: Correct XML syntax (tags, nesting, quoting), not necessarily schema-valid.
Q: When use LEFT JOIN for counts? A: To include parents with zero children in COUNT aggregates.
Q: React controlled input? A: value tied to state plus onChange updating that state.
Q: PHP session_regenerate_id why on login? A: Reduce session fixation risk.
Q: C snprintf vs sprintf? A: snprintf takes a buffer size and reduces overflow risk.
Q: map/filter/reduce in JS? A: Transform, keep matching items, and accumulate values without manual loops.
