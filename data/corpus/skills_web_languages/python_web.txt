# Python for web-relevant work (original)

Python often powers APIs, scripts, and tooling next to HTML/JS front ends.
Functions: def greet(name: str) -> str: return f"Hello, {name}"
Default args: use None sentinels for mutable defaults — never def f(x=[]).
*args and **kwargs collect extras; prefer explicit keyword-only params after * when clarity matters.
Closures and nested defs work; watch late-binding in loops (use default arg binding).
OOP: class User: def __init__(self, email: str): self.email = email
@dataclass for plain data. Properties with @property. Composition over deep inheritance.
dunder methods: __repr__, __eq__, __hash__ carefully for value objects.
Files: with open(path, "r", encoding="utf-8") as f: text = f.read()
Pathlib: Path("data") / "file.json"; path.read_text(encoding="utf-8").
JSON: json.loads / json.dumps; ensure_ascii=False for Persian text; indent=2 for readable files.
Virtual environments isolate deps: python -m venv .venv; pip install from requirements or pyproject.
HTTP server frameworks (conceptual): parse request, validate input, call services, return JSON with correct status codes.
Example tiny handler sketch (teaching only):
def handle_create(body: dict) -> tuple[int, dict]:
    title = body.get("title")
    if not isinstance(title, str) or not title.strip():
        return 400, {"error": "title required"}
    return 201, {"id": "new", "title": title.strip()}
Exceptions: raise ValueError("..."); catch specific types at boundaries.
Logging: logging.getLogger(__name__).exception("failed") in except blocks.
Typing: list[str], dict[str, int], | None; TypedDict for JSON shapes.
Comprehensions: [x.strip() for x in lines if x.strip()]
Generators for streaming large files.
Packaging note: keep web entrypoints thin; business logic importable without starting a server.
Defensive: parameterized SQL via DB-API placeholders; never format user input into SQL strings.
Secrets from environment variables, not source files.
Practice: read a JSON file of users, filter by active flag, write a new JSON summary.
Practice: class Repository with in-memory list and methods add/get/list for a resource.
Q: Why encoding="utf-8"? A: Explicit UTF-8 avoids platform default surprises, especially on Windows.
Q: Why not f-string SQL? A: Injection risk; use bound parameters with the DB driver.
