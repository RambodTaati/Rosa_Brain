# JavaScript basics (original)

JavaScript runs in browsers and (with engines like Node) on servers. This lesson focuses on language core for web pages.
Declare with const by default, let when reassignment is needed, avoid var in modern code.
Types: number, string, boolean, null, undefined, bigint, symbol, and object (including arrays and functions).
typeof null is "object" (historical quirk). Use Number.isNaN, Array.isArray for precise checks.
Strict equality === and !==. == performs coercion — avoid in teaching and production style guides.
Template strings: `Hello, ${name}!`
Objects: const user = { id: 1, name: "Ada" }; access user.name or user["name"].
Arrays: push/pop, map, filter, reduce, find, some, every, includes. Prefer immutable patterns: [...arr, x] over mutating when sharing references.
Destructuring: const { name } = user; const [first, ...rest] = list;
Spread/rest: Math.max(...nums); function f(...args) {}
Functions: function add(a, b) { return a + b; } and const add = (a, b) => a + b;
Arrow functions inherit this lexically — important in callbacks; do not use arrows when you need dynamic this.
Default params: function greet(name = "friend") {}
Modules (ESM): export function parse() {}; import { parse } from "./parse.js"; type="module" on script tags.
Truthy/falsy: 0, "", null, undefined, NaN, false are falsy. Prefer explicit checks for 0 and "".
Optional chaining: user?.profile?.email. Nullish coalescing: value ?? "default" (only null/undefined).
Errors: throw new Error("msg"); try/catch/finally. Catch only when you can handle or translate the error.
JSON: JSON.parse and JSON.stringify. Reviver/replacer for dates if needed.
Date: prefer libraries or Temporal when available; beware timezone pitfalls with Date.
Regular expressions: /pattern/flags or new RegExp — keep readable; comment complex patterns.
Closures: inner functions remember outer bindings — foundation for modules and hooks.
this: depends on call site for function keyword; bind/call/apply to set it; class methods need care when passed as callbacks.
Classes: class Counter { constructor() { this.n = 0; } inc() { this.n++; } }
Map/Set for keyed collections and unique values; WeakMap/WeakSet for memory-sensitive associations.
Promises overview here; deep async in the async lesson.
Strict mode is default in modules. "use strict" in classic scripts.
Debugging: console.log/table, debugger statement, DevTools breakpoints.
Practice: write a pure function that filters a list of products by price range.
Practice: convert a nested callback style sketch into clearer stepwise functions (async lesson continues this).
Q: const vs let? A: const prevents rebinding; let allows reassignment. Both are block-scoped.
Q: Why === over ==? A: === skips type coercion and avoids surprising equalities.
