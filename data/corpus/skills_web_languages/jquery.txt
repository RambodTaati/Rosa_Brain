# jQuery overview (original)

jQuery historically simplified DOM selection, events, and Ajax. Modern browsers and frameworks reduce the need for it, but many legacy apps still use it.
$("selector") selects elements. $(function(){ ... }) runs after DOM ready.
$("#btn").on("click", function() { $(this).text("Clicked"); });
Manipulation: .addClass, .removeClass, .toggleClass, .text, .html (html has XSS risks with untrusted data), .append, .remove.
Ajax: $.ajax / $.get / $.post — prefer fetch in new code; if maintaining jQuery Ajax, still handle errors and CSRF tokens.
Chaining: $("#x").addClass("on").show();
Avoid mixing heavy jQuery DOM mutation with React/Vue on the same nodes.
Migration tip: replace selectors with querySelector, events with addEventListener, Ajax with fetch gradually.
Practice: translate a jQuery click+class toggle into vanilla JS.
Q: Is jQuery required for modern browsers? A: No. Native DOM/fetch cover most former jQuery use cases.
Q: Why be careful with .html()? A: It injects HTML and can enable XSS if the string includes untrusted input.
