# Node.js essentials (original)

Node.js runs JavaScript outside the browser, commonly for HTTP APIs and tooling.
REPL and CLI: node app.js. package.json scripts define start/test/build.
Modules: ESM import/export preferred in new code; CommonJS require still widespread.
const http = require("http"); // or import http from "node:http";
Create a server that listens on a port; always set timeouts in production servers.
Express-style conceptual routing: map method+path to handlers; use middleware for logging, auth, JSON parsing.
Read env with process.env. PORT. Never commit secrets.
fs/promises for async file IO. path.join for safe path concatenation — avoid path traversal by resolving and checking roots.
npm/pnpm/yarn install dependencies into node_modules; lockfiles for reproducible installs.
Error-first callbacks are legacy; prefer promises/async. Unhandled rejections should crash or be logged loudly in production policy.
Clustering and process managers (PM2, systemd) keep services alive — separate from app logic.
Defensive: validate input; helmet-like headers; rate limit; parameterized SQL; run as non-root; keep dependencies updated.
Practice: tiny JSON API sketch returning { ok: true } on GET /health.
Practice: read a UTF-8 file asynchronously and print its length.
Q: Why lockfiles? A: Pin exact dependency trees for reproducible builds and deploys.
Q: Browser JS vs Node? A: Different global APIs (DOM vs fs/http); language syntax is shared.
