# C# essentials (original)

C# is a modern OOP language on .NET, popular for web APIs (ASP.NET Core) and tools.
Console: Console.WriteLine("hi");
Types: int, long, double, bool, string, decimal (money). nullable reference types in modern projects (string?).
var for local inference when obvious. const for compile-time constants; readonly for runtime-set fields.
Classes, structs, records. record Person(string Name, int Age); for immutable data.
Properties: public string Email { get; init; }
LINQ: users.Where(u => u.Active).Select(u => u.Email).ToList();
async Task / await for asynchronous IO — same idea as JS async.
Namespaces and using directives organize code. NuGet packages add libraries.
Exceptions: try/catch/finally; throw; prefer specific exception types.
Pattern matching: switch expressions and is patterns narrow types.
ASP.NET Core conceptual map: controllers/minimal APIs, dependency injection, middleware pipeline, configuration via appsettings and env vars.
Entity Framework or raw ADO.NET with parameters for SQL — never concatenate user input into queries.
Practice: LINQ filter + project a list of products.
Practice: async method that returns Task<string> simulating IO with Task.Delay (teaching only).
Q: Why decimal for money? A: Base-10 precision avoids binary floating-point surprises.
Q: What does await do in C#? A: Yields until the awaited Task completes without blocking a thread the same way a sync wait would.
