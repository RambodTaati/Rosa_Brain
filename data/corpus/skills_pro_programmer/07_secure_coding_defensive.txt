# Defensive secure coding (OWASP-style) — defense only, no exploits or attack steps
Goal: build software that resists common classes of bugs. Rosa_Brain learns defense only.
Input validation: validate type, length, range, charset at trust boundaries; prefer allowlists.
Output encoding: encode for the context (HTML/attr/URL/JS) when emitting untrusted data; prefer frameworks that auto-escape.
Authentication: strong password hashing (argon2/bcrypt); MFA when available; protect session fixation; invalidate on logout/password change.
Session cookies: HttpOnly, Secure, SameSite; short idle timeouts; rotate session ids on privilege change.
Authorization: enforce on server every time; object-level checks; deny default; never trust client role flags.
Secrets handling: env/secret manager; no secrets in repos, logs, or frontend bundles; rotate on leak.
Least privilege: DB users with minimal grants; OS service users; cloud roles narrowed.
Dependency hygiene: pin versions; review advisories; remove unused deps; verify checksums when appropriate.
XSS defense: escape output; CSP as defense-in-depth; avoid innerHTML/v-html with raw user HTML.
CSRF defense: SameSite cookies + CSRF tokens for cookie-based sessions on state-changing requests.
Injection defense: parameterized SQL/NoSQL APIs; never build queries via string concat with user data.
SSRF defense: allowlist outbound URLs; block link-local/metadata IPs for user-controlled fetches.
File upload defense: size limits, type allowlists, random storage names, no executable serving from upload dirs.
Crypto: use vetted libraries; TLS in transit; do not invent protocols.
Logging/monitoring: log auth failures and admin actions; alert on anomalies; never log secrets.
Error messages: generic to clients; detailed internally with ids.
Config hardening: disable debug in prod; secure headers (CSP, X-Content-Type-Options, Referrer-Policy).
Threat mindset: assume clients are hostile; assume multi-tenant data must be isolated.
Incident: rotate secrets, revoke sessions, patch, communicate — without publishing exploit recipes.
